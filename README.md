# TWICE Gacha Collector

Proyecto de fans, sin ánimo de lucro y sin relación con TWICE, JYP Entertainment ni ninguna otra empresa. Juego de colección con sobres, gacha, mascota virtual (Mi Idol) y álbum de cromos.

Este repositorio **no contiene fotos ni vídeos de terceros**: la app los descarga en el navegador de cada persona desde sus fuentes públicas. Las cartas «GAME SPECIAL», los sobres, las rarezas y la mascota son contenido propio del juego, no merchandising oficial.

Tu partida se guarda solo en tu navegador (Perfil → Datos permite exportarla e importarla).
